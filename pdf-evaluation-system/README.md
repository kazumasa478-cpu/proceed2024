# ストレスチェック調査票 読取・集計システム

紙で回答してもらった「職業性ストレス簡易調査票（57項目）」をスキャンしたPDFから、

1. **QRコードで本人を特定**し、本人ごとのフォルダ（`output/ID_氏名/`）にスキャン原本を保存
2. ○の位置を読み取って **回答をExcel（回答確認.xlsx）に記録**
3. 厚生労働省マニュアルの合計点数方式で **採点・高ストレス判定**
4. **本人に手渡す A4 1枚の「結果のお知らせ」PDF**（円グラフ付き）と、**集計Excel**（円グラフ付き）を作成

までを自動で行います。

## 全体の流れ

```
名簿.csv ──(make_forms.bat)──▶ 調査票/調査票_全員分.pdf ──印刷・配布──▶ 本人が○を記入
                                                                        │
                                       スキャン(PDF) ──▶ inbox/ に置く ◀─┘
                                                          │ (run.bat)
                                                          ▼
 output/
 ├─ E0001_山田太郎/
 │   ├─ 調査票スキャン_1枚目.pdf / 2枚目.pdf   … スキャン原本
 │   ├─ 回答確認.xlsx                         … 読取結果（修正可）
 │   └─ 結果通知書_E0001_山田太郎.pdf          … 本人に手渡すA4 1枚
 ├─ 結果通知書_印刷用_全員分.pdf               … まとめて印刷用
 ├─ ストレスチェック集計.xlsx                 … 集計・一覧・回答データ・要確認
 └─ _読取不可/                               … QRやマークが読めなかったページ
```

## 動作環境

- Windows 10/11（macOS・Linux でも可）
- Python 3.10 以上（3.12 推奨）… https://www.python.org/ からインストール。
  インストール時に **「Add python.exe to PATH」にチェック**を入れてください。
- スキャナ：**200〜300dpi、グレースケールまたは白黒、PDF出力**。複数人分をまとめて1つのPDFにしても、ページ順がバラバラでも、上下逆さでも読めます。

## 移設（インストール）手順

1. `pdf-evaluation-system-1.0.0.zip` を任意の場所（例：`C:\stresscheck`）に展開
2. `setup.bat` をダブルクリック（初回のみ。ネット接続が必要。
   オフライン版 zip の場合はライブラリ同梱のためネット不要）
3. `名簿.csv` を編集（Excelで開いて保存してOK）

   | ID | 氏名 | 所属 |
   |----|------|------|
   | E0001 | 山田 太郎 | 営業部 |

4. `config.json` の `report` 欄に、実施者名・相談窓口・面接指導の申出先・実施名を記入

## 使い方

| 手順 | 操作 |
|---|---|
| ① 調査票作成 | `make_forms.bat` → `調査票/調査票_全員分.pdf` ができる（1人2枚、本人のID・氏名・QRコード入り） |
| ② 印刷・配布 | **片面印刷・等倍（「用紙に合わせる」をオフ）**。黒ボールペンで○を付けてもらう |
| ③ スキャン | 回収した用紙をスキャンして PDF を `inbox/` に置く |
| ④ 読取・集計 | `run.bat` → 結果が `output/` にできる。読み終えたPDFは `processed/` へ移動 |
| ⑤ 確認 | 黄色の行（要確認／未記入／複数）があれば、`回答確認.xlsx` で原本を見て「回答」を直し「状態」を **確認済** にする → もう一度 `run.bat` |
| ⑥ 手渡し | `output/結果通知書_印刷用_全員分.pdf` を印刷し、封筒に入れて本人へ |

- 要確認が残っている人の結果通知書は作成されません（誤った結果を渡さないため）。
- 未記入のまま確定する場合も「状態」を「確認済」にすれば、その項目を除いて採点します（通知書に注記されます）。
- 同じ人の用紙を再スキャンすると、その用紙分の回答が上書きされます。
- `run.bat` は inbox が空でも、`回答確認.xlsx` の修正内容からすべての出力を作り直します。

## 採点・判定の方法

- 各項目を「ストレスが高い方を4点、低い方を1点」に換算（逆転項目は 5−回答）。
  逆転項目：A1〜A7、A11〜A13、A15、B1〜B3（`pdfeval/questionnaire.py` の `REVERSED`）
- 高ストレス者の判定（`config.json` の `criteria` で変更可）
  - ① 心身のストレス反応（B 29項目）の合計が **77点以上**、または
  - ② 仕事のストレス要因（A 17項目）＋周囲のサポート（C 9項目）の合計が **76点以上** かつ B が **63点以上**
- 結果通知書の項目別（19尺度）の「良好／ふつう／要注意」は、1項目平均 2.0以下／3.0以上で区切った
  **本システム独自の簡易区分**です（厚労省の素点換算表〔5段階・男女別〕ではありません）。

## 運用上の注意（必ずお読みください）

- ストレスチェックの**実施者は医師・保健師等**である必要があり、個人の結果を**本人の同意なく事業者へ提供することはできません**。
  `output/` フォルダ・集計Excelは実施者（と実施事務従事者）のみがアクセスできる場所で管理してください。
- 判定基準・逆転項目は厚労省「ストレスチェック制度実施マニュアル」の合計点数方式に基づいています。
  **本番運用前に、実施者がマニュアルと照合**してください。
- 所属別集計は、10人未満の集団では個人が特定されるおそれがあるため取扱いに注意してください。
- 自動読取には誤りの可能性があります。初回は数名分を原本と突き合わせて確認してください。
  読取感度は `config.json` の `omr` で調整できます。

## 開発者向け

```bash
python -m pdfeval forms             # 調査票作成 (--separate で1人1ファイル)
python -m pdfeval run               # 読取・集計
python sample/simulate_scan.py      # 手書き風○付きの模擬スキャンPDFを inbox/ に作成（動作確認用）
python -m unittest discover tests   # テスト
python build_package.py             # 移設用zip（通常版）
python build_package.py --offline win --python-version 3.12   # Windows向けオフライン版
```

| ファイル | 役割 |
|---|---|
| `pdfeval/questionnaire.py` | 57項目の設問・逆転項目・尺度・採点 |
| `pdfeval/layout.py` | 調査票の座標（印刷と読取で共通） |
| `pdfeval/forms.py` | QRコード入り調査票PDFの作成 |
| `pdfeval/omr.py` | スキャン画像の位置補正・QR読取・○の読取 |
| `pdfeval/organizer.py` | 本人フォルダ・回答確認.xlsx の保存/読込 |
| `pdfeval/report_pdf.py` | A4 1枚の結果通知書 |
| `pdfeval/excel_report.py` | 集計Excel（円グラフ） |
